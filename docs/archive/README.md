# Archive

This folder holds historical and superseded documentation and records for the
`inference-platform` project — things like retired plans, closed-out migration
notes, or write-ups that described a state of the project which has since moved
on.

**Content here is historical context only.** It reflects decisions, plans, or
project state as of some point in the past, and it is not maintained going
forward. Do not use anything under this folder to understand the current state
of the project, and do not use it to guide new work, design decisions, or
implementation.

If you are a contributor or a coding agent looking for how the project works
today, use the top-level `README.md`, `docs/`, and the current `phase-1-foundations/`
and `phase-2-capstone/` material instead — never this folder.
